# Game Drops

Pensé comme un atelier de pratique de 3 heures, l’objectif est d’appréhender la conception électronique et la programmation informatique par un projet ludique. Avec le lowtech comme point de départ, l’idée est d’utiliser des composants issus de récupérations pour bricoler, reprendre la main, comprendre nos outils avec pour finalité de créer nos propres micro serveurs / jeux vidéo. Le but est ici de nous engager dans une démarche de bricolage et d’approche alternative de l’électronique et d’ainsi révéler le potentiel caché d’objets du quotidien mis au rebus.

Concrètement, sur le plan logiciel, nous allons programmer un microcontrôleur dans le but de réaliser une page web (portfolio, jeu vidéo, manifeste, etc.). Cette page web sera ensuite émise par le microcontrôleur via un signal WiFi. Ensuite, pour la partie matérielle, l’alimentation électrique du dispositif se fera à partir d’objets recyclés (panneau solaires, dynamos, …), autonomes mais non optimisés, non ergonomiques.

Après l’atelier, chacun·e repart avec son objet personnalisé, local mais partageable autour de soi via le signal wifi qu’il décide ou non d’activer. L’alimentation électrique irrégulière rend le tout peu fiable, improductif, et contre toute injonction au capitalisme et à la production de valeur instantanée. 

## Installation

Avant de commencer, assurez-vous d’avoir installé les outils suivants sur votre machine :
- [Arduino IDE](https://www.arduino.cc/en/software/)
- libraires nécessaires pour l'ESP32 (ex: WiFi, WebServer, etc.)
